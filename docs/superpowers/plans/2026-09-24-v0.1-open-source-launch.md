# V0.1 Open-Source Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish Agentic Dev Runner for a first open-source release: fix correctness gaps, add the missing launch CLI commands, package it for npm, and prove the V0.1 release criteria with CI, dogfood, and docs.

**Architecture:** The execution core (workflow engine, scheduler, Git isolation, SQLite persistence, crash recovery, OpenCode/Codex adapters) already exists and stays intact. Changes stay inside existing boundaries: core domain + persistence for the approval runtime state, orchestrator + CLI application layer for the unified run path, platform abstraction for Windows process spawning, and one new publish-only package that bundles the CLI with esbuild.

**Tech Stack:** TypeScript (strict, NodeNext, Node >= 24), pnpm 12.4.1 workspaces, `node:sqlite`, Vitest 5, esbuild (new dev dependency, bundling only), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-24-v0.1-open-source-launch-design.md`

## Global Constraints

- Node engine floor: `>=24.0.0` everywhere (`engines` in published package).
- pnpm version is fixed by `packageManager: pnpm@12.4.1` in the root `package.json`; do not change it.
- License: MIT. Published package name: `agentic-dev-runner` (unscoped), bin `agentic`.
- Strict TypeScript: no `any`, no weakened compiler settings, `exactOptionalPropertyTypes` is on (build optional properties with conditional spreads).
- macOS, Linux, and Windows are first-class. No Bash, no `/tmp`, no shell command strings. Child processes are spawned with argument arrays behind `packages/platform`.
- Persistence goes through the single `RunnerStore` interface. Schema changes are new sequential migrations (v10 next).
- CLI rules (ADR-002): parse input -> call application services -> render. No orchestration, Git, or persistence logic in CLI commands.
- Provider-specific behavior stays inside adapters. No `if provider == ...` in core.
- Verification per task: `pnpm --filter <pkg> test` for the touched packages plus `pnpm typecheck`, `pnpm lint`; run `pnpm build` when the task changes build-relevant wiring. A task is done only with observed passing output.
- One commit per task, conventional-commit style matching repo history (`feat(scope): ...`, `fix(scope): ...`, `test(scope): ...`, `docs(scope): ...`).
- Dependency rule: the only new dependencies allowed by this plan are `esbuild` (dev, bundling, Task 10) and `cross-spawn` + its types (production, platform package, Task 8). Any other dependency requires a plan revision.

## Review Focus

Inputs/conditions the tests below pin, most likely to bite users first:

1. `agentic run <task-id>` on a `default`-workflow task now runs PLAN/PLAN_REVIEW/CODE_REVIEW — the CLI must persist all stage runs and integration verification exactly like unattended execution (Task 5 e2e).
2. Approval must be durable and survive failure/retry: an approved task that fails and is retried must not become `approval-required` again (Tasks 2–4 tests).
3. Windows `.cmd` agent shims must deliver arguments containing spaces, quotes, `%`, and `&` intact (Task 8 test).
4. `retry` at the attempt-budget boundary must refuse, and a retry after a dirty previous attempt must never corrupt state or silently exceed limits (Task 4 tests).
5. Packed CLI must work from a clean install dir with only PATH/HOME overrides, on Windows too (Task 11 pack smoke).
6. Forced kill mid-agent and mid-integration must not leave orphan claims, duplicate merges, or double commits (Task 16).

  async approve(taskId: TaskId): Promise<ApprovalCommandResult> {
    await this.startupReconcile();
    const task = await this.store.getTask(taskId);
    if (task === null) {
      return { kind: "rejected", taskId, message: `task "${taskId}" was not found in runner state` };
    }
    if (!task.definition.approval.required) {
      return { kind: "rejected", taskId, message: `task "${taskId}" does not require human approval` };
    }
    if (task.approvalGrantedAt !== undefined) {
      return {
        kind: "already-granted",
        taskId,
        message: `task "${taskId}" was already approved at ${task.approvalGrantedAt}`,
      };
    }
    if (task.status === "DONE" || task.status === "CANCELLED") {
      return { kind: "rejected", taskId, message: `task "${taskId}" is ${task.status} and cannot be approved` };
    }
    const grantedAt = new Date().toISOString();
    const granted = await this.store.transaction(async () => {
      const recorded = await this.store.approveTask(taskId, grantedAt);
      if (recorded) {
        await this.store.appendEvents([
          {
            type: "task.approval.granted",
            taskId,
            payload: { taskId },
            occurredAt: grantedAt,
          },
        ]);
      }
      return recorded;
    });
    return granted
      ? { kind: "granted", taskId, message: `approval granted for task "${taskId}"` }
      : { kind: "already-granted", taskId, message: `task "${taskId}" was already approved` };
  }
```

  async retry(taskId: TaskId): Promise<RetryCommandResult> {
    await this.startupReconcile();
    const task = await this.store.getTask(taskId);
    if (task === null) {
      return { kind: "rejected", taskId, message: `task "${taskId}" was not found in runner state` };
    }
    if (task.status !== "FAILED" && task.status !== "NEEDS_HUMAN" && task.status !== "BLOCKED") {
      return {
        kind: "rejected",
        taskId,
        message: `task "${taskId}" is ${task.status}; only FAILED, NEEDS_HUMAN, or BLOCKED tasks can be retried`,
      };
    }
    const attempts = await this.store.listAttempts({ taskId });
    const maxAttempts = task.definition.limits.maxAttempts;
    if (attempts.length >= maxAttempts) {
      return {
        kind: "rejected",
        taskId,
        message: `task "${taskId}" exhausted its attempt budget (${String(attempts.length)}/${String(maxAttempts)}); raise limits.max_attempts and re-add the task to allow another attempt`,
      };
    }
    if (task.definition.approval.required && task.approvalGrantedAt === undefined) {
      return {
        kind: "rejected",
        taskId,
        message: `task "${taskId}" requires human approval; run "agentic approve ${taskId}" first`,
      };
    }
    const occurredAt = new Date().toISOString();
    const previousStatus = task.status;
    await this.store.transaction(async () => {
      await this.store.setTaskStatus(taskId, "READY", occurredAt);
      await this.store.appendEvents([
        {
          type: "task.retry.requested",
          taskId,
          payload: { previousStatus, attempts: attempts.length },
          occurredAt,
        },
        {
          type: "task.transitioned",
          taskId,
          payload: { from: previousStatus, to: "READY" },
          occurredAt,
        },
      ]);
    });
    return { kind: "accepted", taskId, message: `task "${taskId}" returned to READY` };
  }
```

  private async routeAndRun(taskId: TaskId): Promise<WorkflowTaskRunOutcome> {
    const task = await this.store.getTask(taskId);
    if (task === null) {
      return { kind: "rejected", taskId, reason: `task "${taskId}" not found` };
    }
    const resolution = resolveWorkflow(task.workflow);
    if (!resolution.resolved) {
      return {
        kind: "rejected",
        taskId,
        reason: `unknown workflow "${task.workflow}" for task "${taskId}"`,
        taskStatus: task.status,
      };
    }
    const selection = await resolveRoutedAgent({
      requiredCapabilities: task.routing.capabilities,
      agentProfiles: this.agentProfiles,
      agents: this.agents,
      adapters: this.adapters,
    });
    if (!selection.routed) {
      return {
        kind: "rejected",
        taskId,
        reason: `no agent profile can route task "${taskId}": ${selection.reason}`,
        taskStatus: task.status,
      };
    }
    return await this.createWorkflowExecutor({
      agent: selection.runtime,
      task,
      workflow: resolution.workflow,
    }).run();
  }
}

```ts
export type DoctorCheckStatus = "PASS" | "WARN" | "FAIL";

export type DoctorCheck = {
  readonly name: string;
  readonly status: DoctorCheckStatus;
  readonly detail: string;
};

export type DoctorReport = {
  readonly checks: readonly DoctorCheck[];
  readonly ok: boolean;
};

export type DoctorEnvironment = {
  readonly nodeVersion: string;
  readonly projectRoot: string;
  readonly storePath: string;
  readonly worktreesDir: string;
  readonly configuration: ProjectConfiguration | null;
  readonly configurationError: string | null;
  readonly projects: readonly Project[];
  readonly agents: readonly AgentStatusEntry[];
  readonly runGitVersion: () => Promise<{ ok: boolean; detail: string }>;
  readonly ensureWorktreesDir: () => Promise<{ ok: boolean; detail: string }>;
};

const MIN_NODE_MAJOR = 24;

export async function runDoctorChecks(env: DoctorEnvironment): Promise<DoctorReport> {
  const checks: DoctorCheck[] = [];
  const nodeMajor = Number.parseInt(env.nodeVersion.split(".")[0] ?? "0", 10);
  checks.push(
    nodeMajor >= MIN_NODE_MAJOR
      ? { name: "node", status: "PASS", detail: `node v${env.nodeVersion} (>= ${String(MIN_NODE_MAJOR)})` }
      : { name: "node", status: "FAIL", detail: `node v${env.nodeVersion} is unsupported; install Node >= ${String(MIN_NODE_MAJOR)}` },
  );
  const git = await env.runGitVersion();
  checks.push({ name: "git", status: git.ok ? "PASS" : "FAIL", detail: git.detail });
  checks.push(
    env.projects.length > 0
      ? { name: "project", status: "PASS", detail: `runner state at ${env.storePath}` }
      : { name: "project", status: "WARN", detail: 'runner is not initialized; run "agentic init"' },
  );
  if (env.configurationError !== null) {
    checks.push({ name: "configuration", status: "FAIL", detail: env.configurationError });
  } else if (env.configuration === null) {
    checks.push({
      name: "configuration",
      status: "WARN",
      detail: "no agentic.yaml found; tasks cannot route agents or resolve verification checks",
    });
  } else {
    checks.push({
      name: "configuration",
      status: "PASS",
      detail: `${String(env.configuration.agentProfiles.length)} agent profile(s), ${String(env.configuration.verificationChecks.length)} verification check(s)`,
    });
  }
  const available = env.agents.filter((agent) => agent.available);
  checks.push(
    available.length > 0
      ? { name: "agents", status: "PASS", detail: available.map((agent) => `${agent.id}${agent.version === null ? "" : ` ${agent.version}`}`).join(", ") }
      : { name: "agents", status: "WARN", detail: `no coding agent is available on PATH (${env.agents.map((agent) => agent.id).join(", ")})` },
  );
  const worktrees = await env.ensureWorktreesDir();
  checks.push({
    name: "worktrees",
    status: worktrees.ok ? "PASS" : "FAIL",
    detail: `${env.worktreesDir} (${worktrees.detail})`,
  });
  return { checks, ok: checks.every((check) => check.status !== "FAIL") };
}
```
